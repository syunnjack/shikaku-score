# 予想問題

**過去問は転載しない。問題文・選択肢・解説はすべて自作し、根拠の条文番号を付ける。**
根拠を書けない問題は入れない（[[tourism-parking-real-data]] と同じ方針）。

## ファイル

    gyosei-01.json   行政書士 予想問題 第1回

## 形式と配点（本試験と同じ）

| 形式 | 問数 | 配点 | 自動採点 |
|---|---|---|---|
| 法令等 択一式 | 40 | 4点 × 40 = 160 | する |
| 法令等 多肢選択式 | 3 | 8点 × 3 = 24 | する（空欄4つ×2点） |
| 法令等 記述式 | 3 | 20点 × 3 = 60 | **しない**（40字は機械で採点できない。自己採点で入れる） |
| 基礎知識 | 14 | 4点 × 14 = 56 | する |

**満点300点。本試験と同じ分母にする。** 分母がずれると判定の意味が無くなる。

## 守ること

- **繰り返しは加点しない。** 同じ問題を何度解いてもスコアは上がらない
- **解答履歴を持たない。** 答えた内容はサーバに送らず、端末にも残さない
- **出した点は、その回の素点としてだけ判定に渡す**
- 記述式は採点しない。**自己採点の点を手で入れてもらう**

```json
  "format": "takuitsu",        // takuitsu / tashi / kijutsu
  "section": "行政法",           // 画面の内訳に使う

  "points": 4,
  "stem": "問題文",
  "choices": ["1の肢", "2の肢", "3の肢", "4の肢", "5の肢"],
  "answer": 3,                  // 1始まり
  "source": "行政手続法5条3項",   // **根拠。空にしない**
  "explain": "なぜその肢が正しいか。条文の文言に沿って書く"
}
```
