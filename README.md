# shikaku-score（erabiyori.jp）— 合格ラインとの距離

**リポジトリ名は shikaku-score だが、公開先は erabiyori.jp。**

得点を入れると、合格ラインまでの距離と判定が出る。宅建と行政書士。

- 公開先: https://erabiyori.jp
- 配信: GitHub Pages（`dist/CNAME` は `SITE_DOMAIN` から作る）
- **入力した内容はどこにも送信されない。** ブラウザの中だけで動く

## スタディングと、どこを変えたか

スタディングのAI実力スコアは「**繰り返し学習した場合**にスコアが高くなる」と
公式に明記されている。つまり「できるか」と「やったか」が1つの数字に混ざっていて、
どちらがどれだけ効いているか利用者に見えない。

繰り返した人が受かりやすいのは事実だろうが、それは相関であって因果ではない。
しかも**教材を使うほど数字が上がる**のは、教材提供者に都合がよい設計でもある。

**ここでは繰り返しを一切加点しない。** 入れた得点だけで判定する。

## 本試験での偏差値は出さない

出すには受験者の得点分布が要る。**宅建も行政書士も、得点分布は公表されていない。**
合格率と合格点から逆算しようにも、式が1本で未知数が2つあり解けない。

**根拠のない偏差値は嘘と同じ**なので出さない。代わりに、公表された合格点だけで
言えることを出す。判定の根拠は「過去◯年のうち何年で合格ラインを超えたか」で、
1行で説明できる。

## 資格で合格基準の性質が違う

| | 宅建 | 行政書士 |
|---|---|---|
| 基準 | **相対**（上位◯%） | **絶対**（180点固定） |
| 合格点 | 毎年動く（31〜38点） | 180点 |
| 足切り | なし | **あり**（法令等122・基礎知識24） |
| 見せ方 | 過去10年で何年合格したか | 180点まであと何点か＋足切り |

**同じ見せ方はできない。** 切り替えられるようにしてある。

**足切りは総合点に埋めない。** 総合が足りていても、基礎知識が24点未満なら不合格。
総合点の内側に隠すと気づけないので、E判定にして理由を書く。

## 模試の分布（行政書士のみ）

実際に受験した模試の得点分布を持っているので、その中での偏差値と順位を出す。

    令和5年の模試 / 104人 / 平均162.3点 / 標準偏差37.1点

**ただしこの母集団は本試験の受験者ではない。** 181点以上が27.9%で、
本試験の合格率14.54%の約2倍。本気の受験生だけが受けている偏った集団なので、
「本試験での位置」として使ってはいけない。画面にもそう書いてある。

**分母にも注意。** この模試は記述式込みの300点満点。
スタディングのAI実力スコアは記述式を除いた240点満点なので、
そのまま入れると意味のない偏差値が出る。入力欄の下に常時警告を出している。

## 数値の確認

`config/exams.json` の `verified` が `false` のあいだは、画面に
「まだ公式で確かめていない」と表示される。**推測で数値を書かない**方針。

    宅建      一般財団法人 不動産適正取引推進機構
    行政書士   一般財団法人 行政書士試験研究センター

受験者数はアフィリエイトサイト経由の数字なので、公式の公表資料で
差し替えてから `verified` を `true` にすること。
